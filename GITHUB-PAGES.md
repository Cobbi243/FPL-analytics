# Як викласти сайт на GitHub Pages

Усе робиться **в браузері** — без терміналу, без встановлення програм. Час: ~10 хвилин.

## Що буде в результаті
Сайт за адресою типу `https://твій-нік.github.io/fpl/` — працює з будь-якого пристрою, ділишся посиланням з друзями. У кожного користувача свій локальний склад, ніхто чужого не бачить.

---

## Крок 1. Створи акаунт GitHub
1. Зайди на https://github.com
2. "Sign up" — зареєструйся (email, пароль, нік)
3. Підтверди email

## Крок 2. Створи репозиторій
1. Праворуч угорі натисни "+" → "New repository"
2. **Repository name**: напиши коротку назву, напр. `fpl` (вона буде в адресі сайту)
3. Постав **Public** (обов'язково — на безкоштовному тарифі Pages працює тільки з публічними)
4. Постав галочку "Add a README file"
5. Натисни "Create repository"

## Крок 3. Завантаж файл сайту
1. У своєму репозиторії натисни "Add file" → "Upload files"
2. Перетягни сюди файл `index.html` (саме так має називатись — не перейменовуй!)
3. Внизу натисни "Commit changes"

## Крок 4. Увімкни GitHub Pages
1. У репозиторії зверху відкрий вкладку "Settings"
2. У лівому меню знайди "Pages"
3. У розділі "Build and deployment" → "Source" обери **"Deploy from a branch"**
4. Нижче "Branch": обери **main**, папку лиши **/ (root)**, натисни "Save"
5. Зачекай 1-2 хвилини

## Крок 5. Готово
Онови сторінку Settings → Pages. Угорі з'явиться:
```
Your site is live at https://твій-нік.github.io/fpl/
```
Це твоє посилання. Відкривай, ділись з друзями. Працює на будь-якому пристрої без реєстрацій.

---

## Як оновлювати сайт пізніше
Коли захочеш нову версію:
1. У репозиторії відкрий `index.html`
2. Натисни значок олівця (Edit) — або видали старий і завантаж новий через "Add file" → "Upload files"
3. "Commit changes"
4. Через 1-2 хв сайт оновиться автоматично

## Часті проблеми
- **Сайт показує 404** — перевір що файл називається саме `index.html` (з маленької літери), і що минуло 2-3 хв після увімкнення Pages.
- **Показує старе** — натисни Ctrl+Shift+R (Cmd+Shift+R на Mac), щоб скинути кеш браузера.
- **Немає розділу Pages у Settings** — переконайся що репозиторій Public.

## Свій домен (опціонально)
Якщо захочеш `fpl-tools.com` замість `github.io`:
1. Купи домен (Namecheap, ~$10/рік)
2. Settings → Pages → "Custom domain" → впиши домен
3. У реєстратора домену додай DNS-записи (GitHub покаже які саме)

## Чому не Firebase?
Тобі не потрібна спільна база даних — у кожного користувача свій приватний склад, що зберігається локально в його браузері. GitHub Pages просто роздає сам сайт (HTML), а вся "пам'ять" живе в браузері кожного. Просто, безкоштовно, приватно.
